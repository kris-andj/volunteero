# Fetch API za klice na backend

- **Status:** sprejeta
- **Datum:** 2026-10-28

## Kontekst in opis problema

Frontend mora pošiljati zahtevke na REST API.

## Obravnavane možnosti

- Fetch API
- Axios

## Odločitev

Izbrala sem »Fetch API«, ker je že vgrajen v brskalnik in ne potrebujem dodatne knjižnice.

## Posledice

### Pozitivne

- Nič ni treba nameščati.

### Negativne

- Napake in JSON moram obdelati sama.
